# Routing

Use this precedence for a child dispatch:

1. Actual native Codex multi-agent tools exposed now.
2. Subagent Broker MCP tools when native tools are absent.
3. Superpowers inline execution fallback.

Do not infer native availability from repository configuration. Inspect the tool list in the current runtime.

For every route, keep system/developer/user/repository instructions authoritative and preserve the task's Superpowers process gates.
